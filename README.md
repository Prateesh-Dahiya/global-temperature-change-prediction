# Global Temperature Change Prediction

## Project Overview
This project focuses on analysing historical global temperature records and exploring patterns of temperature change using data analysis and machine learning.

The project uses historical temperature datasets to study temperature variations across different geographical regions, including cities, states, and countries.

## Dataset

The project uses the following datasets:

- `GlobalTemperatures.csv`
- `GlobalLandTemperaturesByCity.csv`
- `GlobalLandTemperaturesByCountry.csv`
- `GlobalLandTemperaturesByMajorCity.csv`
- `GlobalLandTemperaturesByState.csv`

These datasets contain historical temperature observations across different geographical locations and time periods.

## Project Objectives

- Analyse historical global temperature trends.
- Explore temperature variations across different countries, states, and cities.
- Perform data cleaning and preprocessing.
- Identify patterns and trends in historical temperature records.
- Explore the application of machine learning for temperature prediction.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

1. Load the historical temperature datasets.
2. Perform data cleaning and preprocessing.
3. Handle missing values and prepare the data for analysis.
4. Conduct exploratory data analysis (EDA).
5. Visualise temperature trends and geographical variations.
6. Apply the prediction approach implemented in the notebook.
7. Evaluate and interpret the results.

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/global-temperature-change-prediction.git
```

2. Navigate to the project directory:

```bash
cd global-temperature-change-prediction
```

3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `GlobalTemperatureChangePrediction.ipynb` and run the cells.

This project explores historical global temperature data through data analysis, visualisation, and machine learning techniques. It aims to understand long-term temperature patterns and investigate the use of historical observations for temperature prediction.
